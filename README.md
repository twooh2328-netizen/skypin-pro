# Skypin Pro
드론 촬영지도 앱 프로젝트

최종 목표 기능 정리 (메모용)
1. 지도 기본 기능
Leaflet 기반 지도 표시

OpenStreetMap 타일 불러오기

초기 위치(예: 서울)로 설정

확대/축소, 드래그 이동 가능

2. 메뉴 및 패널 UI
메뉴 버튼: 화면 오른쪽 하단 원형 버튼

패널: 오른쪽에서 슬라이드되는 사이드 패널

패널 닫기 동작

닫기 버튼 클릭 시 닫힘

패널 외부(배경 영역) 클릭 시 닫힘

3. 추천 명소 관리
명소 추가 폼: 이름 입력 후 리스트에 추가

리스트에 카드 형태로 표시 (삭제 버튼 포함)

카드 클릭 시 지도에 마커 표시

4. 촬영지 관리
촬영지 추가 폼: 촬영지 이름, 메모, 사진 업로드

저장 시 리스트에 카드로 표시

카드 안에서 사진 썸네일 미리보기 제공

지도 마커 클릭 시 큰 사진과 상세 메모 표시

삭제 버튼 포함

5. GPS 기능
“내 위치” 버튼 클릭 시 현재 위치를 지도에 표시

마커와 팝업으로 “내 위치” 표시

6. 일출/일몰 계산
“🌅 일출” 버튼 클릭 시 현재 위치 기준으로 오늘의 일출/일몰 시간 계산

패널이나 팝업으로 결과 표시

7. 검색 기능
검색창으로 명소/촬영지 이름 검색

지역별 필터링은 삭제 → 단순 검색만 제공

8. UI/UX 세부 사항
모든 버튼은 세로 정렬

카드와 이미지가 패널 폭에 맞게 표시

리스트 영역은 스크롤 가능

모바일 화면에서도 반응형으로 동작
